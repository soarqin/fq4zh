故事背景

希臘半島的戰爭已結束二十多年。引發戰亂的異世界魔王伽羅被封在地下，殘留的意念卻在地上四處尋找復活的機會。發現一股強大的熱源後，伽羅便將瀕臨毀滅的身體轉移過去。

洛克莉斯原由天地間的精靈統治。大陸各族的紛爭暫告一段落後，人們陸續渡海來到這座富饒的島，精靈也逐漸隱居。各國雖時常為領地起衝突，仍在合作與牽制下維持和平，並推舉勢力最大的波斯王塞內爾為代表。

波斯的領土從洛克莉斯中部延伸到北方。國土廣大、人口較少，即使各地設有堅固的城堡和要塞，仍面臨外敵入侵。塞內爾是天才科學家，也曾苦修並習得數種魔法，因而得以守住領土。

大陸渡海而來的魔法師宙出任參謀後，塞內爾性情大變。波斯的兵力突然增加，民眾卻紛紛逃往鄰國，指控國王已將心交給魔物。波斯城傳出詭異的聲響，據說城裡冒出的瘴氣能使生靈發狂。塞內爾似乎已掌握操縱人心和用魔法造兵的方法。

諸侯匆忙加強防守，卡利恩王艾雷斯則試圖刺殺塞內爾，失手被擒。波斯趁勢進兵，吞併卡利恩的領地。神祕人擊倒獄卒、解開牢門，教艾雷斯駕馭鐵嘴神鷹，讓他得以逃回卡利恩城。

艾雷斯的戀人愛倫是一名勇敢的戰士。她聽說艾雷斯被捕，立即離城營救。艾雷斯回來後，沒有人知道她的下落。城中只剩少數守軍，多數部隊似乎已敗在波斯軍手下。艾雷斯號召諸侯起兵反抗時，許多領主已歸附波斯。敵軍攻破卡利恩在泰納里斯河畔的要塞，渡河逼近城下。

啟動、讀檔與結束

啟動選單

啟動遊戲後，在「FQ4 啟動選單」設定畫面與音效，選「開始」播放片頭。開場影片可按 Enter 或滑鼠左鍵略過。

畫面模式
「視窗模式」以 640 × 480 啟動，之後可調整大小。選「全螢幕模式」時，可在右側下拉選單指定解析度。
音效設定
可選「關閉音效」、「開啟音效，關閉音效特效」或「開啟音效與音效特效」。此處也能調整「背景音樂音量」與「效果音音量」，可先試聽預設音量。音效特效可能增加 CPU 負荷。原版以 DirectX 9.0 的音訊元件播放音效。若遇到音效相容性問題，可先關閉音效特效，或選「關閉音效」。
重設遊戲內視窗
啟動時恢復遊戲內的預設視窗配置。縮小解析度後若有視窗移出可操作範圍，可使用此選項。
停用透明混合
以不透明方式繪製原本半透明的畫面。遊戲變慢時，可試著停用透明混合或縮小視窗、降低全螢幕解析度。

開始新遊戲或繼續遊戲

在標題畫面選「從頭開始」，再選難度。新遊戲的開場事件會自動進行，按 Enter 或滑鼠左鍵可繼續對話。選「繼續遊戲」可從存檔清單載入進度。

難度效果
無參戰敵軍強度與「普通」相同，敵軍不會呼叫援軍。
初學者敵軍比「普通」弱。
普通標準敵軍強度。
熟練敵軍比「普通」強。
苦鬥Windows v1.10 選單中的額外難度。

結束遊戲

進入「營地」，在世界地圖選「結束遊戲」，再選「是」。也可以按 Alt + F4，或在視窗模式按右上角的關閉按鈕。

遊戲流程與敗北條件

指揮數支部隊向敵方據點推進。劇情推進時會有角色和部隊加入，也可透過「外交」爭取中立國。部隊在世界地圖設定目的地，再用「時間經過」推進。進入區域地圖後，改用滑鼠或鍵盤直接控制角色。

作戰時可利用有利地形、屬性相剋和魔法。一次戰鬥最多可派兩支我方部隊，依照疲勞情況輪換。視戰況派一支部隊也可作戰，還能用特定魔法或道具召喚助力。

艾雷斯死亡，或敵軍攻入卡利恩城時，遊戲結束。主線沒有通關必備道具，持有道具的隊員陣亡後仍可繼續劇情。

視窗操作

主視窗會跟隨正在操控的角色，並一直開啟。也可從主選單開啟輔助視窗，查看各處戰況。危險視窗可用滑鼠直接操控其中的角色。

  • 調整大小。用滑鼠左鍵拖曳視窗左下或右下角的小方塊。縮小主視窗可露出後方的個人狀態欄，也可加快最高速時的畫面更新。
  • 移動視窗。拖曳視窗左上角的小方塊，放開即可固定位置。
  • 切換前後順序。按一下露在外面的視窗，可將它移到最上層。在地圖畫面按滑鼠右鍵可輪換重疊順序。
  • 關閉輔助視窗。按視窗框右上角的 ×。

區域地圖的基本操作

取得艾雷斯的控制權後便可開始行動。平時畫面只顯示隊長。遇敵時隊員自行作戰，結束後回到隊長身邊。角色與敵人相鄰時會自動交戰。開啟「自動戰鬥」後，正在操控的角色也會自行追擊敵人。

移動和切換角色

  • 把滑鼠游標移向視窗中央角色的上、下、左或右方，按住左鍵帶動角色。鍵盤可用數字鍵盤的 8、2、4、6 分別向四個方向移動。
  • 對狀態欄中某名角色的 HP 或 ST 按滑鼠右鍵，即可接手操控。也可按 ← 或 → 選人，再按 Enter 確定。HP 數字以黑底反白顯示的是目前操控的角色。角色陷入危險時，HP 數字會變色。
  • 兩支我方部隊同時在場時，可按 ↑ 或上方的「切換部隊」圖示。要讓另一支部隊離開地圖，先切換過去，再操控隊長走向出口。

射箭、施法與使用道具

操控有相應能力的角色，按 Space 或在角色身上按滑鼠左鍵，即可射箭、施放選定的魔法或使用主動道具。同一角色同時持有可主動使用的道具，又能射箭或施法時，優先使用道具。多數道具只要持有就會生效，其他角色也會自行射箭或施法。

下馬

騎馬的角色可能進不了建築或狹窄通道。可按上方的「特殊指令」圖示並選「下馬」，也可按 ↓，再選「執行」。在目前地圖下馬後，換到另一張地圖才會恢復騎乘。建築內須徒步行動。

離開區域

多數區域可從上緣或下緣離開。通常要操控隊長走到出口。沒有敵軍時，畫面會提示「進入營地」並返回世界地圖。戰鬥中離開可能遺下陷入危險的隊員。看到警告時可用 Esc、數字鍵盤 0 或滑鼠右鍵取消，走散的隊員有時會在別處重逢。

出口通往哪一區由目前地圖決定。戰鬥結束時，仍留在場上的參戰部隊會返回原區域。探索時也可調查門和洞窟入口，或從人物對話取得線索。

操作選單和對話

在區域地圖按 Home 開啟主選單。將滑鼠移到項目上會移動手指游標，再按左鍵確定。鍵盤可用數字鍵盤的 8、2 上下選擇，再按 Enter 確定。能取消的畫面可按 Esc、數字鍵盤 0 或滑鼠右鍵。

狀態顯示

狀態欄位於遊戲視窗後方。縮小主視窗即可露出欄位。拖曳欄位名稱可以重新排列，按住 Ctrl 拖曳可微調位置。帶有 C 標記的是正在操控的部隊。對角色的 HP 或 ST 按滑鼠右鍵可切換操控對象。

在「系統」的「狀態顯示設定」中，選「操控部隊設定」或「非操控部隊設定」，再切換所需的欄位。

欄位意義
HP目前生命力，降到 0 時角色死亡。
ST狀態圖示，包括一般、陣亡、追擊、攻擊、撤退、中毒、石化、混亂和停止。旁邊的 ＋ 表示角色受到地形加成（GE）。

區域連接圖

區域之間的連接方式可在遊戲地圖上查看。

區域地圖選單與圖示

Home 開啟主選單。選單上方顯示目前操控部隊的隊長姓名。按 F12，或在畫面空白的黑色區域按滑鼠右鍵，可切換左上方的指令圖示。用 Esc、數字鍵盤 0 或滑鼠右鍵關閉選單。

部隊指令

可向目前場上的第一部隊，以及以增援身分到場的第二部隊下令。正在生效的指令會反映在圖示上。

指令部隊行動
一般指令維持以隊長為中心的隊型，遭攻擊時應戰。
攻擊指令各隊員主動前往迎敵。隊員陷入危險時仍可能自行撤退。
撤退指令朝部隊進入這張地圖的方向撤退。按住 Shift 也能暫時下達此指令。要撤離地圖，須親自操控隊長走過出口。
停止指令暫停未受玩家操控的隊員。

上表四項指令同時只有一項生效，效力限於目前區域。進入新區域時，預設採用「攻擊指令」。召喚角色自行行動。

特殊指令

  • 「下馬」讓騎乘成員在目前地圖徒步行動。
  • 「丟掉弓箭」可提高部分弓手的攻擊和防禦。棄弓後須到武器店透過轉職取回弓箭。
  • 「交涉」可在戰況非常有利或不利時嘗試。部隊需要具備交涉能力的成員。若交涉成功，可能有機會安全撤退。每場戰鬥最多交涉一次。

切換部隊

兩支我方部隊在同一張地圖時，可選「切換部隊」或按 ↑ 更換操控對象。換過去的部隊會取得狀態欄的 C 標記。兩支部隊的第一、第二部隊身分照舊。

隊型

用「隊型」選單或圖示設定部隊移動時的排列。「隊型１」、「隊型２」、「隊型３」是預設戰鬥隊型。「一列隊型」讓隊員排在隊長身後。「自訂」會套用已記下的排列。

要建立自訂隊型，在安全處下達「停止指令」，逐一操控角色站位，再選「設定自訂隊型」。自訂隊型不會寫入存檔。

標記

選「標記」或對應圖示後，可用「標示隊長」標出目前操控的角色，或選「全員標示」標出所有友軍。選「除去標記」可清除標記。

視窗

選「視窗」或對應圖示，再指定要「開啟」或「關閉」的視窗。編號顯示在視窗框左上角。初次開啟的輔助視窗會縮小顯示在左側，可用滑鼠調整位置和大小。

編號與設定追蹤對象
1　非操控部隊設定跟隨另一支我方部隊的隊長。
2　敵軍視窗設定跟隨敵軍隊長。
3　危險視窗設定追蹤瀕危的我方角色。可用滑鼠就地操控。
4　自由視窗設定查看地圖中指定的位置。

前 3 種視窗在沒有追蹤對象時會顯示「待命中」。

系統

  • 「狀態顯示設定」控制主視窗後方的欄位是否顯示。「狀態位置設定」可調整狀態配置，「生命力顯示方式」可選「數字顯示」或「量表顯示」。
  • 「遊戲速度設定」可調整行動和動畫速度，從慢速、普通到快速。按住 Ctrl 時會暫時以最高速執行。
  • 「自動戰鬥」開啟後，目前操控的角色也會自行作戰。
  • 「開場部隊指令」可預先指定進入區域時的部隊行動。

魔法選擇

先切換到有魔法能力的角色，再選「魔法選擇」、按對應圖示或按 F3。選好後，按 Space 或在角色身上按滑鼠左鍵施法。卡魯也在這裡更換獸衣。

呼叫援軍

當交戰區域或鄰近區域有可用的友軍，而且場上只有一支我方部隊時，可從清單選出援軍。選中的部隊會以第二部隊身分加入戰鬥。已撤離的部隊也可再次呼叫回來。

營地

可紮營時，使用「營地」選單、圖示或 F1 返回世界地圖。沒有敵軍時，從地圖的上緣或下緣離開也能返回。回到世界地圖後，即可移動其他部隊和存檔。

紮營須等戰鬥結束，並離開城堡、屋內、地下城等內部區域。

世界地圖操作

時間經過 · 部隊移動 · 探索 · 外交 · 編制 · 資料 · 勢力圖 · 記錄與結束遊戲

在選單和區域圖示以外的地圖空白處按住滑鼠左鍵，可向該方向捲動。也可按住任一方向鍵，同時按數字鍵盤的 8、2、4 或 6 捲動。另按住 Ctrl 可加快捲動。

把游標移到區域上，右下方會顯示地名。若有部隊駐紮，按左鍵可查看部隊清單和戰力。戰力依人數、兵士強度和武器計算。敵軍圖示朝前，友軍朝後，中立部隊朝側面。

時間經過

每執行一次「時間經過」，敵我部隊會交替行動。已設定目的地的部隊會向目的地前進一格，所有部隊的疲勞都會略微恢復。進入城堡或要塞，或與敵軍相遇而開戰時，畫面會切換到區域地圖。

部隊移動

  1. 選「部隊移動」，再從清單選擇部隊。滑鼠游標下方會出現旗幟。
  2. 在世界地圖上點選目的地。左上方會顯示所選地名，若有敵軍也會列出其隊長和戰力。
  3. 按滑鼠左鍵或右鍵開啟「確認目的地」，再選「確定」。
  4. 選「時間經過」，讓部隊開始前進。

要清除原有目的地，可再次選擇同一部隊，在設定目的地時取消。

探索

在世界地圖選「探索」，再選一支我方部隊，即可進入該部隊所在的區域。要探索其他地方，先讓部隊抵達。進入區域後，左上角會顯示部隊名稱。

部隊行軍時可能經過重要地點。使用「探索」才能發現部分村鎮、洞窟、隊友、怪物和寶藏。探索也能累積等級與軍資金。想挑戰用更短時間擊敗敵軍，也可以少做探索。要回到世界地圖，使用「營地」。

外交

選「外交」，先指定出使的部隊，再選外交對象。範圍包括部分城堡，以及我方部隊所在區域鄰近的中立部隊或敵軍。出使人物和時機都可能改變交涉結果。

直接用「部隊移動」進入他國領土，可能使中立國轉為敵對。可以觀察守衛的反應，再決定如何接觸。

編制

「編制」可以調動隊員、建立部隊、解僱隊員和交換道具。隊員姓名前有頭盔標記，表示具備領導能力。每支部隊最左側的成員是隊長，由缺乏領導能力的人擔任隊長會使部隊變弱。艾雷斯的位置固定。最多可編制 20 支部隊。

交換隊員或更改順序

  1. 選第一部隊，再從同區域的部隊中選第二部隊。只要調整同一支部隊的順序時，第一、第二部隊都選該部隊。
  2. 用滑鼠或數字鍵盤選一名隊員。反向的手指游標會標出已選位置。
  3. 選另一名隊員以交換位置，或選部隊最右側的空格將人移入。兩支部隊同時顯示時，也能在其中一支部隊內調整順序。

建立部隊

第一部隊選要拆分的部隊，第二部隊選「新部隊」，再依交換隊員的方式將人移入。

解僱隊員

  1. 第一部隊選要調整的部隊，第二部隊選「解僱」。
  2. 將要解僱的隊員移到下方清單。
  3. 按 Esc、數字鍵盤 0 或滑鼠右鍵開啟確認視窗，再選「解僱」。

裝備、交換與卸下道具

  • 先選要調整的部隊，再選「ITEM BOX」開啟道具箱。
  • 選一名隊員時，反向的手指游標會標出該隊員。再選另一名隊員可交換道具，或選道具箱內的道具來裝備。選中的道具名稱會以綠字顯示。
  • 選隊員和「卸下」，可將裝備放回道具箱。其他區域的部隊也能透過同一個道具箱取用。
  • 未鑑定的道具會顯示「道具效果不明」。可到有鑑定師的魔法店查明效果。

轉職、成長與招募

轉職

等級上限是 99，轉職後會保留等級，也可以維持目前職業繼續升級。不同職業可能讓角色較不容易逃跑、能反彈箭矢，或取得擔任隊長的資格。

在武器店轉職
符合條件的角色可付費轉職，例如讓他國兵士改編為我方兵士、讓兵士成為弓兵，或讓「士兵」轉成「戰士」。費用因轉職對象而異。
讓卡利恩士兵成為騎士
士兵達到所需等級後，可由卡利恩城的大主教授予騎士稱號，取得領導部隊的資格。在世界地圖選「外交」和「卡利恩城」，派該士兵所在的部隊前往王室深處找大主教。
讓騎士成為騎兵
卡利恩的騎士可以在某處的馬廄轉為騎兵，也可透過「外交」前往。部分劇情事件也會使角色轉職。

提升等級

升級依據是命中敵人的次數。攻擊率（AR）高的角色通常更快提高等級。

疲勞累積與恢復

每次攻擊敵人或遭受攻擊都會累積疲勞（FT），戰力也會隨之下降。強者較容易疲勞，與防禦高的敵人作戰時也容易累積疲勞。

讓部隊休息即可逐漸恢復，也可用道具或住旅店恢復。作戰時可輪換部隊，避免同一支部隊連續交戰。城內的敵方隊長和部隊在戰後回復得較快，宜盡量一戰取勝。

爭取盟友

從世界地圖選「外交」前往對方首領所在處，可以接觸中立國或敵方將領。時機、局勢和出使者會影響結果。先貿然進軍也可能使局勢改變。與一方結盟有時會使另一方敵對，原手冊建議可依喜好選擇盟友。

招降敵人

擊倒敵方隊長後，人形敵兵有時會倒戈，逃跑的敵兵較有可能加入。從兩側包抄，也可能比較容易捕獲他們。
