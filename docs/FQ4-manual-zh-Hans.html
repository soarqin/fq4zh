故事背景

希腊半岛的战争已结束二十多年。引发战乱的异世界魔王伽罗被封在地下，残留的意念却在地上四处寻找复活的机会。发现一股强大的热源后，伽罗便将濒临毁灭的身体转移过去。

洛克莉斯原由天地间的精灵统治。大陆各族的纷争暂告一段落后，人们陆续渡海来到这座富饶的岛，精灵也逐渐隐居。各国虽时常为领地起冲突，仍在合作与牵制下维持和平，并推举势力最大的波斯王塞内尔为代表。

波斯的领土从洛克莉斯中部延伸到北方。国土广大、人口较少，即使各地设有坚固的城堡和要塞，仍面临外敌入侵。塞内尔是天才科学家，也曾苦修并习得数种魔法，因而得以守住领土。

大陆渡海而来的魔法师宙出任参谋后，塞内尔性情大变。波斯的兵力突然增加，民众却纷纷逃往邻国，指控国王已将心交给魔物。波斯城传出诡异的声响，据说城里冒出的瘴气能使生灵发狂。塞内尔似乎已掌握操纵人心和用魔法造兵的方法。

诸侯匆忙加强防守，卡利恩王艾雷斯则试图刺杀塞内尔，失手被擒。波斯趁势进兵，吞并卡利恩的领地。神秘人击倒狱卒、解开牢门，教艾雷斯驾驭铁嘴神鹰，让他得以逃回卡利恩城。

艾雷斯的恋人爱伦是一名勇敢的战士。她听说艾雷斯被捕，立即离城营救。艾雷斯回来后，没有人知道她的下落。城中只剩少数守军，多数部队似乎已败在波斯军手下。艾雷斯号召诸侯起兵反抗时，许多领主已归附波斯。敌军攻破卡利恩在泰纳里斯河畔的要塞，渡河逼近城下。

启动、读档与结束

启动菜单

启动游戏后，在「FQ4 启动菜单」设置画面与音效，选「开始」播放片头。开场影片可按 Enter 或鼠标左键略过。

画面模式
「窗口模式」以 640 × 480 启动，之后可调整大小。选「全屏模式」时，可在右侧下拉菜单指定分辨率。
音效设置
可选「关闭音效」、「开启音效，关闭特效」或「开启音效与特效」。此处也能调整「背景音乐音量」与「效果音音量」，可先试听默认音量。音效特效可能增加 CPU 负荷。原版以 DirectX 9.0 的音频组件播放音效。若遇到音效兼容性问题，可先关闭特效，或选「关闭音效」。
重置游戏内窗口
启动时恢复游戏内的默认窗口配置。缩小分辨率后若有窗口移出可操作范围，可使用此选项。
停用透明混合
以不透明方式绘制原本半透明的画面。游戏变慢时，可试着停用透明混合或缩小窗口、降低全屏分辨率。

开始新游戏或继续游戏

在标题画面选「新游戏」，再选难度。新游戏的开场事件会自动进行，按 Enter 或鼠标左键可继续对话。选「继续游戏」可从存档列表加载进度。

难度效果
无参战敌军强度与「普通」相同，敌军不会请求援军。
新手敌军比「普通」弱。
普通标准敌军强度。
熟练敌军比「普通」强。
苦斗Windows v1.10 菜单中的额外难度。

结束游戏

进入「营地」，在世界地图选「结束游戏」，再选「是」。也可以按 Alt + F4，或在窗口模式按右上角的关闭按钮。

游戏流程与败北条件

指挥数支部队向敌方据点推进。剧情推进时会有角色和部队加入，也可通过「外交」争取中立国。部队在世界地图设置目的地，再用「推进时间」推进。进入区域地图后，改用鼠标或键盘直接控制角色。

战斗时可利用地形优势、属性克制和魔法。一次战斗最多可派两支我方部队，依照疲劳情况轮换。视战况派一支部队也可作战，还能用特定魔法或道具召唤助力。

艾雷斯死亡，或敌军攻入卡利恩城时，游戏结束。主线没有通关必备道具，持有道具的队员阵亡后仍可继续剧情。

窗口操作

主窗口会跟随正在操控的角色，并一直开启。也可从主菜单开启辅助窗口，查看各处战况。危险窗口可用鼠标直接操控其中的角色。

  • 调整大小。用鼠标左键拖动窗口左下或右下角的小方块。缩小主窗口可露出后方的个人状态栏，也可加快最高速时的画面更新。
  • 移动窗口。拖动窗口左上角的小方块，放开即可固定位置。
  • 切换前后顺序。按一下露在外面的窗口，可将它移到最上层。在地图画面按鼠标右键可轮换重叠顺序。
  • 关闭辅助窗口。按窗口框右上角的 ×。

区域地图的基本操作

取得艾雷斯的控制权后便可开始行动。平时画面只显示队长。遇敌时队员自行作战，结束后回到队长身边。角色与敌人相邻时会自动交战。开启「自动战斗」后，正在操控的角色也会自行追击敌人。

移动和切换角色

  • 把鼠标光标移向窗口中央角色的上、下、左或右方，按住左键带动角色。键盘可用数字键盘的 8、2、4、6 分别向四个方向移动。
  • 对状态栏中某名角色的 HP 或 ST 按鼠标右键，即可接手操控。也可按 ← 或 → 选人，再按 Enter 确定。HP 数字以黑底白字显示，代表当前操控的角色。角色陷入危险时，HP 数字会变色。
  • 两支我方部队同时在场时，可按 ↑ 或上方的「切换部队」图标。要让另一支部队离开地图，先切换过去，再操控队长走向出口。

射箭、施法与使用道具

操控有相应能力的角色，按 Space 或在角色身上按鼠标左键，即可射箭、施放选定的魔法或使用主动道具。如果角色既能射箭或施法，又持有可主动使用的道具，优先使用道具。多数道具只要持有就会生效，其他角色也会自行射箭或施法。

下马

骑马的角色可能进不了建筑或狭窄通道。可按上方的「特殊指令」图标并选「下马」，也可按 ↓，再选「执行」。在当前地图下马后，换到另一张地图才会恢复骑乘。建筑内须徒步行动。

离开区域

多数区域可从上边缘或下边缘离开。通常要操控队长走到出口。没有敌军时，画面会提示「进入营地」并返回世界地图。战斗中离开可能会把遇险的队员留在战场上。看到警告时可用 Esc、数字键盘 0 或鼠标右键取消，掉队的队员有时会在别处重逢。

出口通往哪一区由当前地图决定。战斗结束时，仍留在场上的参战部队会返回原区域。探索时也可调查门和洞窟入口，或从人物对话取得线索。

操作菜单和对话

在区域地图按 Home 开启主菜单。将鼠标移到项目上会移动手指光标，再按左键确定。键盘可用数字键盘的 8、2 上下选择，再按 Enter 确定。能取消的画面可按 Esc、数字键盘 0 或鼠标右键。

状态显示

状态栏位于游戏窗口后方。缩小主窗口即可显示状态栏。拖动字段名称可以重新排列，按住 Ctrl 拖动可微调位置。带有 C 标记的是正在操控的部队。对角色的 HP 或 ST 按鼠标右键可切换操控对象。

在「系统」的「状态显示设置」中，选「操控部队设置」或「非操控部队设置」，再选择需要显示的字段。

字段含义
HP当前生命力，降到 0 时角色死亡。
ST状态图标，包括一般、阵亡、追击、攻击、撤退、中毒、石化、混乱和停止。旁边的 ＋ 表示角色受到地形加成（GE）。
ITEM道具图标。
LV等级。
MXHP最大生命力。
NAME姓名简写，最左边是队长。简体版的状态栏最多显示两个完整汉字，可在世界地图的「资料」查看全名。
AT／AR攻击力／攻击率。
DF／DR防御力／防御率。
AD／AA箭矢防御／箭矢闪避。

区域连接图

区域之间的连接方式可在游戏地图上查看。

区域地图菜单与图标

Home 开启主菜单。菜单上方显示当前操控部队的队长姓名。按 F12，或在画面空白的黑色区域按鼠标右键，可切换左上方的指令图标。用 Esc、数字键盘 0 或鼠标右键关闭菜单。

部队指令

可向当前场上的第一部队，以及以增援身份到场的第二部队下令。正在生效的指令会反映在图标上。

指令部队行动
一般指令维持以队长为中心的阵型，遭攻击时应战。
攻击指令各队员主动前往迎敌。队员陷入危险时仍可能自行撤退。
撤退指令朝部队进入这张地图的方向撤退。按住 Shift 也能暂时下达此指令。要撤离地图，须亲自操控队长走过出口。
停止指令暂停未受玩家操控的队员。

上表四项指令同时只有一项生效，效力限于当前区域。进入新区域时，默认采用「攻击指令」。召唤角色自行行动。

特殊指令

  • 「下马」让骑乘成员在当前地图徒步行动。
  • 「丢弃弓箭」可提高部分弓手的攻击和防御。弃弓后须到武器店通过转职取回弓箭。
  • 「交涉」可在战况非常有利或不利时尝试。部队需要具备交涉能力的成员。若交涉成功，可能有机会安全撤退。每场战斗最多交涉一次。

切换部队

两支我方部队在同一张地图时，可选「切换部队」或按 ↑ 更换操控对象。换过去的部队会取得状态栏的 C 标记。两支部队的第一、第二部队身份照旧。

阵型

用「阵型」菜单或图标设置部队移动时的排列。「阵型１」、「阵型２」、「阵型３」是默认战斗阵型。「一列阵型」让队员排在队长身后。「自定义」使用已保存的排列。

要建立自定义阵型，在安全处下达「停止指令」，逐一操控角色站位，再选「自定义阵型」。自定义阵型不会写入存档。

标记

选「标记」或对应图标后，可用「标记队长」标出当前操控的角色，或选「标记全员」标出所有友军。选「清除标记」可清除标记。

窗口

选「窗口」或对应图标，再指定要「开启」或「关闭」的窗口。编号显示在窗口边框的左上角。初次开启的辅助窗口会缩小显示在左侧，可用鼠标调整位置和大小。

编号与设置追踪对象
1　非操控部队设置跟随当前未操控的我方部队队长。
2　敌军窗口设置跟随敌军队长。
3　危险窗口设置追踪濒危的我方角色。可用鼠标就地操控。
4　自由窗口设置查看地图中指定的位置。

前 3 种窗口在没有追踪对象时会显示「待命中」。

系统

  • 「状态显示设置」控制主窗口后方显示哪些状态栏字段。「状态位置设置」可调整状态配置，「生命力显示方式」可选「数字显示」或「条形显示」。
  • 「游戏速度设置」可调整行动和动画速度，从慢速、普通到快速。按住 Ctrl 时会暂时以最高速执行。
  • 「自动战斗」开启后，当前操控的角色也会自行作战。
  • 「初始部队指令」可预先指定进入区域时的部队行动。

魔法选择

先切换到有魔法能力的角色，再选「魔法选择」、按对应图标或按 F3。选好后，按 Space 或在角色身上按鼠标左键施法。卡鲁也在这里更换兽衣。

请求援军

当交战区域或邻近区域有可用的友军，而且场上只有一支我方部队时，可从列表选出援军。选中的部队会以第二部队身份加入战斗。已撤离的部队仍可再次请求增援。

营地

可扎营时，使用「营地」菜单、图标或 F1 返回世界地图。没有敌军时，从地图的上边缘或下边缘离开也能返回。回到世界地图后，可以移动其他部队，也可以存档。

扎营须等战斗结束，并离开城堡、屋内、地下城等内部区域。

世界地图操作

推进时间 · 部队移动 · 探索 · 外交 · 编制 · 资料 · 势力图 · 记录与结束游戏

在菜单和区域图标以外的地图空白处按住鼠标左键，可向该方向滚动。也可按住任一方向键，同时按数字键盘的 8、2、4 或 6 滚动。同时按住 Ctrl 可加快滚动。

把光标移到区域上，右下方会显示地名。若有部队驻扎，按左键可查看部队列表和战力。战力依人数、士兵强度和武器计算。敌军图标朝前，友军朝后，中立部队朝侧面。

推进时间

每执行一次「推进时间」，敌我部队会交替行动。已设置目的地的部队会向目的地前进一格，所有部队的疲劳都会略微恢复。进入城堡或要塞，或与敌军相遇而开战时，画面会切换到区域地图。

部队移动

  1. 选「部队移动」，再从列表选择部队。鼠标光标下方会出现旗帜。
  2. 在世界地图上点击目的地。左上方会显示所选地名，若有敌军也会列出其队长和战力。
  3. 按鼠标左键或右键开启「确认目的地」，再选「确定」。
  4. 选「推进时间」，让部队开始前进。

要清除原有目的地，可再次选择同一部队，在设置目的地时取消。

探索

在世界地图选「探索」，再选一支我方部队，即可进入该部队所在的区域。要探索其他地方，先让部队抵达。进入区域后，左上角会显示部队名称。

部队行军时可能经过重要地点。使用「探索」才能发现部分村镇、洞窟、队友、怪物和宝藏。探索也能提升等级并积累军费。想挑战用更短时间击败敌军，也可以少做探索。要回到世界地图，使用「营地」。

外交

选「外交」，先指定出使的部队，再选外交对象。范围包括部分城堡，以及我方部队所在区域邻近的中立部队或敌军。出使人物和时机都可能改变交涉结果。

直接用「部队移动」进入他国领土，可能使中立国转为敌对。可以观察守卫的反应，再决定如何接触。

编制

「编制」可以调动队员、建立部队、解雇队员和交换道具。队员姓名前有头盔标记，表示具备领导能力。每支部队最左侧的成员是队长，由缺乏领导能力的人担任队长会使部队变弱。艾雷斯的位置固定。最多可编制 20 支部队。

交换队员或更改顺序

  1. 选第一部队，再从同区域的部队中选第二部队。只要调整同一支部队的顺序时，第一、第二部队都选该部队。
  2. 用鼠标或数字键盘选一名队员。反向的手指光标会标出已选位置。
  3. 选另一名队员以交换位置，或选部队最右侧的空格将人移入。两支部队同时显示时，也能在其中一支部队内调整顺序。

建立部队

第一部队选要拆分的部队，第二部队选「新部队」，再依交换队员的方式将人移入。

解雇队员

  1. 第一部队选要调整的部队，第二部队选「解雇」。
  2. 将要解雇的队员移到下方列表。
  3. 按 Esc、数字键盘 0 或鼠标右键开启确认窗口，再选「解雇」。

装备、交换与卸下道具

  • 先选要调整的部队，再选「ITEM BOX」开启道具箱。
  • 选一名队员时，反向的手指光标会标出该队员。再选另一名队员可交换道具，或选道具箱内的道具来装备。选中的道具名称会以绿字显示。
  • 选队员和「卸下」，可将装备放回道具箱。其他区域的部队也能通过同一个道具箱取用。
  • 未鉴定的道具会显示「道具效果不明」。可到有鉴定师的魔法店查明效果。

道具

有些魔法店设有鉴定师。鉴定过的道具可在营地用「编制」开启道具箱，查看其效果。「道具效果不明」表示尚未鉴定。

道具分为持有即生效，以及需要操作才能生效的类型。要主动使用道具，操控持有者后按 Space，或在角色身上按鼠标左键。相同召唤角色已在场时，再用道具也无法召唤同一角色。

转职、成长与招募

转职

等级上限是 99，转职后会保留等级，也可以维持当前职业继续升级。不同职业可能让角色较不容易逃跑、能反弹箭矢，或取得担任队长的资格。

在武器店转职
符合条件的角色可付费转职，例如让他国兵士改编为我方兵士、让兵士成为弓兵，或让「士兵」转成「战士」。费用因转职对象而异。
让卡利恩士兵成为骑士
士兵达到所需等级后，可由卡利恩城的大主教授予骑士称号，取得领导部队的资格。在世界地图选「外交」和「卡利恩城」，派该士兵所在的部队前往王室深处找大主教。
让骑士成为骑兵
卡利恩的骑士可以在某处的马厩转为骑兵，也可通过「外交」前往。部分剧情事件也会使角色转职。

提升等级

升级依据是命中敌人的次数。攻击率（AR）高的角色通常更快提高等级。

疲劳累积与恢复

每次攻击敌人或遭受攻击都会累积疲劳（FT），战力也会随之下降。强者较容易疲劳，与防御高的敌人作战时也容易累积疲劳。

让部队休息即可逐渐恢复，也可用道具或住旅店恢复。作战时可轮换部队，避免同一支部队连续交战。城内的敌方队长和部队在战后回复得较快，宜尽量一战取胜。

争取盟友

从世界地图选「外交」前往对方首领所在处，可以接触中立国或敌方将领。时机、局势和出使者会影响结果。先贸然进军也可能使局势改变。与一方结盟有时会使另一方敌对，原手册建议可依喜好选择盟友。

招降敌人

击倒敌方队长后，人形敌兵有时会倒戈，逃跑的敌兵较有可能加入。从两侧包抄，也可能比较容易捕获他们。
